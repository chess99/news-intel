The new WebMCP standard proposal lets sites expose tools (e.g., JavaScript functions and HTML forms) to in-browser AI agents, which can thus reliably simulate user actions instead of resorting to possibly expensive (e.g., on-screen reading) and often unreliable guesswork (e.g., DOM scraping).&lt;/p&gt; &lt;p&gt;Google explained the motivation as follows:&lt;/p&gt; &lt;blockquote&gt; &lt;p&gt;By defining these tools, you can instruct agents exactly how and where to interact with your site. The result? An agent can now call machine-friendly functions to complete complex tasks in seconds with greater reliability, precision, and personalization. Imagine a user is planning a multi-city vacation. Instead of watching an agent click through travel forms, they can authorize it to query backend APIs directly to instantly build a personalized, weather-optimized itinerary for their approval.&lt;/p&gt; &lt;/blockquote&gt; &lt;p&gt;Without WebMCP, an AI agent wanting to act on behalf of the user would download the DOM for relevant web pages, understand the roles of the buttons on the page, take and analyze some screenshots, and deduce the coordinates for a simulated mouse click on the relevant button. As &lt;a href=&quot;https://www.scalekit.com/blog/webmcp-the-missing-bridge-between-ai-agents-and-the-web&quot;&gt;often noted&lt;/a&gt;, the process can be non-deterministic and token-expensive: a CSS layout shift or a delayed ad load can break the entire automation loop; image processing, even for low-resolution images, is the source of added latency and token consumption.&lt;/p&gt; &lt;p&gt;As with the standard backend-focused &lt;a href=&quot;https://modelcontextprotocol.io/docs/getting-started/intro&quot;&gt;Model Context Protocol (MCP)&lt;/a&gt;, web authors can provide an explicit API for AI agents to perform personalized tasks on behalf of human users. WebMCP, however, operates entirely on the client side. WebMCP is purpose-built for the browser and omits various server-side concepts, such as &lt;a href=&quot;https://modelcontextprotocol.io/specification/2025-06-18/server/resources#resources&quot;&gt;resources&lt;/a&gt;. Essentially, WebMCP helps agents reliably understand Web UI by defining APIs that provide agents with a menu of named, typed, and described actions they can call directly.&lt;/p&gt; &lt;p&gt;The specification defines two API surfaces.
