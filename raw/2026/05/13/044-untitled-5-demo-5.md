带着这些问题，我们和Vbot维他动力创始人兼CEO余轶南博士聊了一个小时。以下是经过编辑的对话实录。 &nbsp; 一、做物理世界的机器人，量产才是最大的难关 &nbsp; 极客公园 ：首先恭喜完成新一轮融资，资方最看重你们的是什么？ &nbsp; 余轶南 ：最核心的一点，是我们用一年半的时间，证明了我们能把这件事从头到尾跑通。从产品设计、结构研发、电气研发，到AI算法、供应链管理、生产制造、全渠道销售、用户交付，整个全链条我们都打通了。 &nbsp; 具身智能不是一个单点技术，它需要硬件、软件、算法、商业的完整闭环。很多团队可能某一块很强，但没有全栈能力，就走不到量产这一步。我们向行业证明了，我们能以最快的速度拿出顶级水平的产品，并且实现规模销售。 &nbsp; 极客公园 ：你们成立于2024年底，到现在已经完成了四轮融资，这个节奏算快吗？ &nbsp; 余轶南 ：其实放到具身这个行业里，这个节奏真不算快，本来还可以更快。我们中间停了一段时间，没有融资，全部精力都放在产品开发和渠道建设上。 &nbsp; 这一轮融资的核心节点就是量产。接下来我们今年还会再融几轮，因为这个行业的发展速度太快了，你必须有足够的弹药才能跑在前面。 &nbsp; 极客公园 ：我五一去了北京蓝色港湾的体验店，人蛮多。但同时也在社交媒体上看到有用户吐槽交付推迟了。量产过程中是不是遇到了超出预期的困难？ &nbsp; 余轶南 ：我们的demo去年四五月份就出来了，当时已经能跑很多场景了。但从一个能跑的demo，到一个能批量交付的合格产品，中间有一道巨大的鸿沟，这道鸿沟比想象的还要深。 &nbsp; 去年年底我们发布产品并开启预定，到今年4月底开启全款支付，中间整整5个月，我们一直在解决量产中的工艺问题，我们做了三轮完整的产线试制，所有零部件全部开模、做大规模准入测试，前前后后解决了上千个软硬件bug。 &nbsp; 这个过程非常痛苦，但真正能走出来的企业才会有市场。事实上，大部分硬件创业公司都是死在这个阶段的。尤其是做物理世界的机器人，量产才是最大的难关。 &nbsp; 极客公园 ：有没有哪个具体的问题，花了你们特别多的时间去解决？ &nbsp; 余轶南 ：我举一个最典型的例子：结构件强度。我之前做了十年汽车产业，一直以为汽车的结构件强度是消费品里最高的，所以我们一开始就按照汽车的最高标准来设计。 &nbsp; 结果做出来一测试，完全不够用。机器人是一直在运动的，关节不断接触地面，承受的冲击非常大。我们最后测出来，机器人某些关键部件的强度峰值要求，是汽车的5倍。 &nbsp; 而且机器人还不能用钢这种太重的材料，必须兼顾重量和强度。所以我们只能换材料、换工艺，反复迭代，最后终于把这个问题解决了，但代价就是成本大幅上升，交付也推迟了。 &nbsp; 首批500台 Vbot 超能机器狗在 Vbot 超能工厂正式量产下线｜图片来源：维他动力 &nbsp; 极客公园 ：现在产能要从每月1500台爬到2500台，供应链和品控能跟得上吗？ &nbsp; 余轶南 ：我们做了非常多的准备。最核心的一点，是把品控前移，直接管控上游一级核心供应商的生产工艺和出厂检测。我们给供应商配备了专门的检测设备，制定了非常严格的流程，把有问题的部件全部拦截在生产端，而不是等到组装的时候才发现。 &nbsp; 现在我们的零部件良品率已经提升到了一个非常好的水平，组装端的效率也在不断提高。6月份做到2500台/月是完全没有问题的。 &nbsp; 二、用户比我们想象的更爱它：日均交互80次 &nbsp; 极客公园 ：现在首批用户已经拿到产品了，真实的用户画像和你们之前的预期一致吗？ &nbsp; 余轶南 ：基本上完全符合我们的预判。其实在产品出来之前，我们就调研了200个已经购买过四足机器人的用户，总结出了几个核心特征： 有6-12岁孩子的三口/五口之家，占比超过50% 绝大多数是新能源汽车用户和iPhone用户 不是价格敏感型，而是科技敏感型，最大的销量其实出现在中上价格带，用户愿意为好的技术和产品买单 这次我们自己的用户数据出来，和这个画像几乎一模一样。唯一超出预期的是，有老人的家庭占比也很高，很多人买给父母做陪伴。 &nbsp; 图片来源：维他动力 &nbsp; 极客公园 ：用户的实际使用情况怎么样？有没有超出你们预期的数据？ &nbsp; 余轶南 ：用户时长和交互频次超出了我们的想象。平均下来，核心用户每天的使用时长在4-6个小时，包括在家交互、出门遛狗；日均交互次数超过80次。 &nbsp; 这个数字是什么概念？智能汽车的日均交互次数大概是十几次，手机上的AI助手也就二三十次，而且都是功能性的，比如导航、开空调。但我们的用户和机器狗是聊天式的交互，一来一回，小朋友甚至可以跟它聊几十个来回。 &nbsp; 现在日活也非常稳定，不是刚买回去新鲜几天就不用了。很多用户真的把它当成了家里的一份子，每天早晚各遛一次，就像遛真狗一样。 &nbsp; 极客公园 ：用户用得最多的功能是什么？ &nbsp; 余轶南 ：排在第一位的肯定是陪伴和娱乐，尤其是对小朋友来说。然后是教育功能，这个是很多家长特别喜欢的。比如机器狗可以给孩子讲课本知识，更重要的是它可以全程用英文和孩子对话，这种沉浸式的英语学习效果，比看书上课好太多了。 &nbsp; 还有远程视频、家庭安防、老人守护这些功能，使用率也很高。 &nbsp; 极客公园 ：有没有一些你们完全没想到的用户用法？ &nbsp; 余轶南 ：C端的用法基本都在我们的预期之内，但B端的需求是一个意外之喜。因为我们的产品硬件配置非常高，性价比又好，很多行业客户找上门来，用我们的机器狗做二次开发。 &nbsp; 比如各种巡检：物业巡检、工厂巡检、农业巡检、仓储巡检；还有农药喷洒、管道检测这些场景。这一点特别像大疆，大疆本来是做C端无人机的，结果很多行业应用也都用大疆的产品。 &nbsp; 这件事让我想到了拓竹3D打印。在拓竹之前，3D打印几乎全是B端市场，拓竹把C端产品做好之后，现在C端已经占到了整个市场的8成以上，出货量远远超过了所有工业3D打印公司的总和。我觉得具身智能也会走同样的路。 &nbsp; 不过目前B端的需求只占总销量的5%不到，C端还是绝对的核心。长期来看，C端的市场规模也一定是远大于B端的。B端需求虽然多，但非常分散，每个场景的量都不会特别大。 &nbsp; 极客公园 ：现在的商业模式是怎样的？主要靠硬件销售吗？ &nbsp; 余轶南 ：目前是的，现阶段我们最核心的目标就是出货量、规模和用户满意度。我们在整机价格里已经打包了基础的4G流量和AI Token费用，大部分用户完全够用。 &nbsp; 对于使用量特别大的用户，我们提供了一个几十块钱一个月的增值服务包，包含额外的流量和Token。但这部分不是我们现在的主要收入来源。 &nbsp; 未来的商业模式会是三层：第一层是硬件销售，第二层是周边配件，第三层是软件订阅和应用服务。第三层会是最大的市场，就像手机上的APP一样。现在我们已经有很多用户在买配件了，未来我们会不断丰富配件和应用生态。 &nbsp; 三、为什么先四足后人形？Vbot要做的是生活空间机器人平台 &nbsp; 极客公园 ：很多人说你们的机器狗是「行业顶配」，这个顶配具体体现在哪些地方？ &nbsp; 余轶南 ：主要是四个方面： 第一，高功率密度的关节电机，比行业平均水平高了将近50%，动力非常强； 第二，极简的传感器配置，我们没有堆一堆摄像头和激光雷达，就用一对双目+一个激光雷达+四麦克风，符合第一性原理，就像人只有一对眼睛和两只耳朵一样； 第三，594Wh的高能量密度电池，续航能做到4-5个小时，这个是行业里最好的水平，很多比我们体积大很多的机器狗，续航也做不到这个水平； 第四，也是最重要的一点，我们在端侧放了128TOPS的AI算力。现在行业里绝大部分机器狗，甚至很多人形机器人，端侧算力只有5-10TOPS，基本上就是"无大脑机器人"，只能跑运控。 我们在端侧配置了128TOPS的AI算力，这是目前量产机器人里配置的最高算力。 现在行业里很多机器狗，甚至部分人形机器人，端侧算力只有5-10TOPS，更多只能完成基础运动控制；但家庭场景里的机器人，需要同时完成环境理解、语音交互、多模态感知和实时决策，对端侧算力要求极高。 只有把算力拉满，用户才能在使用里无感的完成和机器人的交互。 &nbsp; 这四个点加起来，让我们的产品在硬件上做到了行业标杆级的水平，而且成本控制得非常好。 &nbsp; 极客公园 ：你们把这款产品定义为"具身智能平台"，而不是一个单一的硬件产品，这个怎么理解？ &nbsp; 余轶南 ：历史上的电子产品分为两种：一种是功能性产品，比如相机、录音笔，你买的时候就知道它能干什么，功能边界非常清晰；另一种是平台型产品，比如PC和手机，它的价值是不断增长的，上面会跑各种各样的应用。 &nbsp; 我们认为机器人一定是平台型产品。机器狗的移动能力、交互能力、负重能力、导航能力，这些都是平台性的能力，本身不直接产生价值。但在这些能力之上，可以长出无数的应用：家居中控、非接触式健康监测、老人陪伴、儿童教育、随行跟拍、小件物品递送、宠物远程照顾、AI交互编程等等。 &nbsp; 过去一年我们主要完成了平台本身的开发，今年我们会把重点放在应用侧，把平台的价值做厚。 &nbsp; 极客公园 ：现在整个行业都在卷人形机器人，你们为什么选择先做四足，再做人形？ &nbsp; 余轶南 ：这是一个商业路径的选择问题。具身智能有两个最大的不确定性：技术不确定性和商业不确定性。我们希望先解决商业的确定性，再去攻克技术的不确定性。 &nbsp; 四足机器人的硬件和软件架构相对成熟，我们可以用最快的速度打通从供应链到销售的全链条，验证市场需求。而且做四足积累下来的所有核心能力&mdash;&mdash;电子电器架构、传感器、供应链、操作系统、AI模型、数据飞轮&mdash;&mdash;这些东西100%可以复用到人形机器人上。 &nbsp; 很多公司先做人形，结果就是demo做了一个又一个，永远无法量产，也无法验证商业价值。我们先把四足做起来，有了收入、有了用户、有了数据，再做人形就会顺理成章得多。 &nbsp; 极客公园 ：你们的人形机器人研发进展怎么样了？会是一个什么样的产品？ &nbsp; 余轶南 ：我们今年就会出人形机器人的样机。我们的目标非常明确：既要好看，又要好用。 &nbsp; 现在市场上绝大多数人形机器人都不美观，大家要么觉得它是进工厂干活的，不用在乎好不好看；要么觉得它是个玩具，不用在乎好不好用。但我觉得伟大的产品一定是既好看又好用又好玩的，就像iPhone和Mac一样。 &nbsp; 人形机器人最适合的场景是：商场、餐厅、写字楼、公共设施、家庭。这些地方需要和人打交道，好看就非常重要。同时它又要能真正干活，解决实际问题。 &nbsp; 极客公园 ：你们在技术上的核心布局是什么？ &nbsp; 余轶南 ：三个核心方向： 第一，全尺寸人形机器人的本体研发，兼顾运动能力和任务能力； 第二，手足一体的世界模型研发，覆盖通用操作和移动能力。我们采用的是"分开训练+隐空间token融合"的方案，世界模型负责感知、记忆和预测，全身运动控制和操作模型负责具体执行，最后通过隐空间的token进行融合微调； 第三，Agentic OS架构的具身智能系统研发，这是机器人的操作系统，未来所有的应用都会跑在这个上面。我们基于OpenAgent的架构做了深度优化，实现了任务拆解、技能调用、上下文管理等核心能力，并且大幅提升了调度效率。 &nbsp; 现在整个行业的技术路线正在从发散走向收敛。硬件方面，关节电机、传感器、灵巧手的技术都在快速成熟；软件方面，三层模型架构已经越来越清晰：上层是VRL模型做意图理解和任务规划，运行频率0.1-1Hz；中间是隐空间世界模型做感知、记忆和预测，运行频率10-20Hz；下层是反应式视觉语言动作模型做实时控制，运行频率50-100Hz以上。 &nbsp; 谁能把这个技术链条整合成一个完整系统，谁就能拿到通往终局的钥匙。 &nbsp; 四、未来，物理AI的通用模型会不会出现？ &nbsp; 极客公园 ：现在很多人还是会把消费级机器人当成玩具，你怎么看这个认知？ &nbsp; 余轶南 ：我觉得没有必要刻意去消解这个认知。好玩本身就是一个非常重要的价值，甚至是比有用更重要的价值。你会发现今天刚需的东西反而不好卖，又好玩又好用的东西才最好卖。 &nbsp; 但问题是，你不能只是一个纯玩具。如果一万多块钱买一个只能玩三个月的玩具，大部分消费者是不会买单的。我们的产品必须做到既好玩又有用，这样才能成为所有家庭的标配。 &nbsp; 极客公园 ：很多人担心机器人进入家庭后的隐私问题，你们是怎么解决的？ &nbsp; 余轶南 ：我们有三个基本原则： 第一，没有必要绝对不上传数据，所有能在端侧处理的，全部在端侧处理，并且做端侧脱敏。我们的设备本地可以存储大量视频数据，没有用户的主动操作，绝对不会将数据上传到云端； 第二，所有数据上传必须获得用户的明确授权，用户不同意，绝对不能传； 第三，即使数据上传到了云端，所有权也完全属于用户，没有用户授权，我们绝对不会使用这些数据。 &nbsp; 这是全球通用的原则，也是我们做产品的底线。 &nbsp; 极客公园 ：如果2026年整个行业只能验证一个关键问题，你觉得会是什么？ &nbsp; 余轶南 ：我觉得是：到底存不存在一个通用的物理AI模型，可以适配所有的场景和所有的机器人本体？ 今天的互联网大模型已经证明，一个通用模型可以同时完成数字世界里的多个场景的任务。但在物理世界，这件事还没有被验证。 机器人面对的是完全不同的真实环境：不同家庭、不同空间、不同机器人形态，甚至不同的运动方式。 未来到底能不能有一个通用的物理AI模型，同时适配这些复杂场景和不同机器人？如果有，那整个具身智能行业的发展速度会比我们想象的快更多。 维他动力 机器狗 人形机器人 分享至
