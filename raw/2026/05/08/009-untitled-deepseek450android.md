Anthropic 与 SpaceX 达成算力协议，获超 22 万块英伟达 GPU 今天凌晨，Anthropic 宣布与 SpaceX 达成算力合作协议，将使用 SpaceX Colossus 1 数据中心的全部算力资源。依据协议，Anthropic 将在本月内获得逾 300 兆瓦的新增算力，涉及超过 22 万块英伟达 GPU。 Anthropic 表示，这批新增算力将直接用于提升 Claude Pro 和 Claude Max 订阅用户的服务容量。Anthropic 同步宣布对 Claude Code 及 Claude API 的使用限制进行调整，即日起生效。 将 Claude Code 的五小时速率限制提升一倍，适用于 Pro、Max、Team 及按席位计费的 Enterprise 方案； 取消 Pro 和 Max 账户在高峰时段的 Claude Code 限速降级机制； 大幅提高
