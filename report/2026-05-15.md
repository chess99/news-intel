**腾讯开源 Agent 记忆压缩方案，Token 消耗最高降低 61%**

腾讯开源 TencerDB Agent Memory 记忆压缩方案，声称多任务连续 Session 场景 Token 消耗最高降低 61%，任务成功率最高提升 51%。驱动力在于 Agent 任务链路持续延长导致上下文窗口快速占满、Token 成本攀升，扩窗口和压缩摘要等现有方案无法有效解决结构化记忆管理问题。该方案基于结构化任务图（Mermaid 任务画布）设计，与业内 Agent 记忆研究方向一致。值得注意的是，测试环境（模型版本、硬件配置）和具体任务数量未披露，"最高"数字对应的边界尚不清晰。此前端腾讯已开源 Agent 执行底座 Cube（两周 5000 星），属连续技术布局。
