## 📋 值得关注

**MS Edge 密码明文加载问题**（Solidot ⭐⭐⭐）
安全研究人员发现Edge启动时在内存中明文预解密所有保存的密码，Chrome则采用按需解密策略。Edge的设计优先响应速度，代价是内存中始终存在完整明文密码，增加了被恶意程序抓取的风险。技术细节有限，实际可利用场景尚不明确。

**GitHub + Microsoft Defender for Cloud 正式GA**（GitHub Changelog ⭐⭐⭐）
GitHub Advanced Security与Microsoft Defender for Cloud集成正式发布，打通代码→构建产物→运行时安全风险追踪。需GitHub Enterprise Advanced Security许可。这是微软持续整合安全产品线的一步，与近期Copilot深度集成开发平台的战略一致。
